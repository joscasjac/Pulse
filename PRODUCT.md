# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
Pulse is project delivery inside ERPNext. The requested backlog in BACKLOG.md remains the complete functional scope. Native Project, Task, assignments and Timesheet records are canonical.

## Users
Teams planning project tasks, reviewing requests, documenting work and tracking client delivery. Specific industry and company size are not specified.

## Operating Context
An authenticated Frappe/ERPNext workspace, with project membership and role permissions, desktop and mobile browser access. Real data must remain visible and editable through supported APIs.

## Brand Commitments
Keep the name Pulse. The user explicitly requested a major redesign resembling makeplane/plane in appearance and organization, with simplicity and clarity as the priority. Use the actual Plane product interface as visual reference; implement original Vue components.

## Product Principles
- Make the next action clear.
- Separate personal, workspace and project navigation.
- Keep advanced tools available through progressive disclosure.
- Preserve all implemented backlog capabilities and permission boundaries.
- Use real data, honest empty states and recoverable errors.
