# Archived documentation (DEPRECATED)

These 21 documents (00–20) describe an **earlier, abandoned architecture** for Pulse in which:

> "A Pulse card **is** an ERPNext Task; a Pulse project **is** an ERPNext Project."
> Governing rule: *Reuse ERPNext → Extend ERPNext → Build new.*

That direction was **reversed on 2026-07-06**. Pulse is now a **standalone, plug-and-play Frappe app** with **zero dependency on ERPNext or any other app**, and **no Pulse data linked to non-Pulse doctypes**.

These files are kept only for historical reference. **Do not treat them as current.** The single source of truth is now [`../_canonical-model.md`](../_canonical-model.md).
