# Native ERPNext records own project work

The fork is intended to run inside ERPNext, and its executable code already uses native Project and Task despite upstream documentation describing standalone records. Keep native Project, Task and Frappe assignments, and consolidate time into native Timesheet Detail so delivery, billing and customer work share one record rather than maintaining competing copies. Pulse owns the agile extensions; legacy Pulse records require explicit, idempotent migration and preserved provenance.
